## 2024-06-19 - Replacing outline-none with focus-within:ring
**Learning:** In this codebase, adding `outline-none` to inputs removes standard browser focus indicators entirely. If an input is wrapped in a container that provides the visual "field" (like the rounded background in search and chat), applying `focus-within:ring-2 focus-within:ring-{color}` to the wrapper provides an accessible and aesthetically pleasing focus indicator that encompasses the entire input area. Furthermore, icon-only `<label>` elements acting as implicitly-labeled wrappers should include visually hidden `sr-only` text.
**Action:** When removing default outlines using `outline-none` for styling purposes, ensure focus states are restored by adding `focus-within:ring-*` classes on the wrapping container. Always ensure implicitly labeled inputs have an `aria-label` or an `sr-only` span inside the label.
