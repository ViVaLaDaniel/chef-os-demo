## 2024-07-22 - Restoring Keyboard Focus and Labels on Custom Inputs
**Learning:** When using `outline-none` on an `<input>` nested inside a container designed to look like the input border (e.g. `bg-white p-2 rounded-3xl`), native keyboard focus styling is lost, rendering the element inaccessible to keyboard users. Additionally, relying on `placeholder` attributes without an accessible name (`<label>`, `aria-label`, or `.sr-only` text) leaves screen readers without a clear field description.
**Action:** Always pair `outline-none` on inner inputs with `focus-within:ring-2 focus-within:ring-amber-500` (or the primary brand color) on the wrapping container. Always ensure inputs without visible labels have either `aria-label` or visually hidden (`sr-only`) text for screen readers.
