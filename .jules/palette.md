## 2024-10-14 - Restore Focus Rings on Composite Inputs
**Learning:** When using `outline-none` on inner `<input>` elements inside composite component wrappers (like a `<label>` with an icon or a styled `<div>` for chat input), keyboard accessibility is lost because the browser's default focus ring is removed and not replaced. Relying solely on placeholders without an `aria-label` also creates an accessibility gap for screen readers.
**Action:** Apply `focus-within:ring-2 focus-within:ring-amber-500` (using the app's primary active color) to the outer wrapper container so the focus ring is clearly visible when the inner input receives focus. Always ensure the inner `<input>` has an explicit `aria-label` (e.g., `aria-label="Поиск"`) when it relies solely on placeholder text or lacks a visually associated explicit `<label>`.
