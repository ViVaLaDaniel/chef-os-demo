## 2024-05-19 - Accessible Focus States for Input Containers
**Learning:** In composite input components where an inner `<input>` uses `outline-none` (to remove default focus rings) and relies on an outer container (like `div` or `label`) for its visual styling, keyboard focus indicators are completely lost. Additionally, relying solely on placeholder text for screen readers is insufficient if the inner `<input>` lacks an explicit `aria-label` or visually associated `<label>`.
**Action:** Always apply `focus-within:ring-2 focus-within:ring-amber-500` (or the appropriate active state color) to the outer wrapper container so the focus ring remains visible when the inner input receives focus. Also, ensure the inner `<input>` element has a descriptive `aria-label` (in Russian, as per project conventions) for screen reader accessibility.
