## 2024-09-06 - Input Wrapper Accessibility Focus States
**Learning:** For composite input components where an inner `<input>` uses `outline-none`, apply `focus-within` classes (e.g., `focus-within:ring-2 focus-within:ring-amber-500`) to the outer wrapper container (like the `div` or `label`) so the focus ring is visible when the inner input is active. Also, ensure the inner `<input>` has an explicit `aria-label` if it relies solely on `placeholder` text or lacks a visually associated `<label>`.
**Action:** Always check composite input wrappers (divs or labels containing inputs with `outline-none`) and add `focus-within` styling so keyboard users can clearly see when they are focused, as standard outlines are suppressed. Ensure `aria-label` is present for screen readers.
