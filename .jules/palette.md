## 2024-08-27 - Focus Visible Styles for Composite Inputs
**Learning:** When creating composite input components (like a search box with an icon, or a chat input with a send button) where the inner `<input>` element uses `outline-none` to suppress default browser outlines, keyboard users lose the visual focus indicator. Applying `focus-within:ring-2 focus-within:ring-amber-500` to the outer wrapper element (e.g., the `label` or `div` containing both the input and the icon/button) restores a clear, accessible focus ring for the entire composite component when the inner input is active.
**Action:** Always verify keyboard focus states (tab navigation) for inputs with `outline-none`. For composite inputs, apply `focus-within` styles to the parent wrapper container to ensure keyboard accessibility is maintained.
